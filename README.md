## ?? Installation and Local Setup  
Follow these instructions to spin up the local development deployment environment in your machine:  
  
1. Clone the project repository online:  
```cmd  
git clone https://github.com  
cd campus-event-management  
```  
  
2. Install all required software application package assets:  
```cmd  
npm install  
```  
  
3. Boot up the unified Express application server:  
```cmd  
node backend/server.js  
```  
  
4. Launch your interface canvas:  
Open `frontend/index.html` inside any standard web browser application.  
  
## ?? Core Architecture REST Endpoints  
- `GET  /api/status` : Verifies full structural availability of the runtime system configuration context.  
- `GET  /api/events` : Reads and displays all seeded academic university events directly from our database.  
- `POST /api/events` : Creates a new entry row inside our target SQLite Events storage data matrix.  
- `POST /api/register` : Records a custom student reference relationship registration entry.  
- `POST /api/login` : Handles security session access payload authorization matching parameters.
